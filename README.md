# ☕ Starbucks Beverage Nutrition Dashboard

## 📌 Project Overview

This project presents an interactive Tableau dashboard that analyzes the nutritional composition of Starbucks beverages. The dashboard enables users to explore calorie content, sugar levels, caffeine, fat, protein, and other nutritional metrics to identify healthier beverage options and uncover trends across drink categories.

---

## 🎯 Objectives

- Analyze the nutritional content of Starbucks beverages.
- Compare beverages based on calories, sugar, caffeine, and fat.
- Identify healthier drink options.
- Create an interactive dashboard for easy data exploration.
- Generate business insights using data visualization.

---

## 📂 Dataset

**Dataset:** Starbucks Beverage Nutrition Dataset

The dataset includes nutritional information for Starbucks beverages, such as:

- Beverage Category
- Beverage Name
- Calories
- Total Fat
- Saturated Fat
- Carbohydrates
- Sugar
- Protein
- Caffeine
- Serving Size

## 🔍 Key Insights

- Coffee-based beverages generally contain higher caffeine levels.
- Frappuccino beverages tend to have higher calorie and sugar content.
- Tea and brewed coffee options are generally lower in calories.
- Nutritional values vary significantly across beverage categories.
- Interactive filtering allows quick comparison between drink types.
